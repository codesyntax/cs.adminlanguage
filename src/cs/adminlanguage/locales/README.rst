Adding and updating locales
---------------------------

For every language you want to translate into you need a
locales/[language]/LC_MESSAGES/cs.adminlanguage.po
(e.g. locales/de/LC_MESSAGES/cs.adminlanguage.po)

For German

.. code-block:: console

    $ mkdir de

For updating locales

.. code-block:: console

    $ ./update.sh
